Gray Balance L*a*b*

These three plots show the lightness variation (L*) and any color casts in gray (a* and b*).
L* shows lightness — the lower the value the darker the color.

a* shows the red-to-green hue axis. A positive value is red; a negative value is green.

b* shows the yellow-to-blue hue axis. A positive value is yellow; a negative value is blue.
