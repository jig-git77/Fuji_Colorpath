System Requirements
  • MacOS 10.11 or newer, or Windows 8.1 / 10 / 11
  • Firefox, Chrome, or Edge
  • An active ColorPath SYNC Validation license
  • DYMO LabelWriter 400, 450, or 550
Install DYMO Software

DYMO printer drivers must be installed prior to connecting. Follow the instructions provided by DYMO to install DYMO Connect (for LabelWriter 450 and 550) or DYMO Label Software (for LabelWriter 400).

For the LabelWriter 550, DYMO Connect must be opened to detect the labels in the printer before it will print.

Additional Steps for Windows

  1. In the Windows Control Panel, navigate to Devices and Printers.
  2. Right click on the DYMO LabelWriter device and choose Printing Preferences.
  3. Change the Orientation to landscape.
  4. Click Advanced...
  5. Change the Paper size to 30256 Shipping.
  6. Click OK on both windows to confirm the changes.
Printing Validation Labels
  1. On the label preview page, click Print. The browser's Print dialog will appear.
  2. Choose the DYMO LabelWriter and click More Settings.
  3. Set the Paper size to any of the following:
    30256 Shipping Shipping Address 2.31 by 4.00 inches custom 58.76x101.6mm.
  4. Set the Margins to Default and the Orientation to Landscape.
  5. Click Print.
